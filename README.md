# Calculator 1.0

A beginner-level calculator built using Python.

## Features

- Addition, subtraction, multiplication, and division.
- Exponentiation.
- Error handling for invalid numerical input.
- Division-by-zero protection.
- Repeated calculations without restarting the program.
- Case-insensitive responses when choosing whether to continue.

## Technologies Used

- Python

## How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open the project in PyCharm or another Python editor.
4. Run `calculator.py`.

## About

This project was created as part of my journey learning Python programming. It helped me practise variables, conditional statements, loops, and exception handling.
